# Form Causality Prototype Batch 03
更新日: 2026-09-15

## テーマ
「Factを載せる」から **Factが造形・構図・Motionを生む**へ。

## FC-01 Translation
Truth: 「分かりやすく説明する」

Bad: 見出しに“分かりやすく説明します”。

Good:
- technical term
- semantic grouping
- plain language
へ画面自体が変化。

Pass question: そのTruthを消したら、このMotionは存在理由を失うか？

## FC-02 Accumulation
Truth: 300社以上の支援経験。

Bad: `300+`を巨大表示。

Good: 相談断片が蓄積し、最終的に代表的な問題群へ整理される。

Difference: Number is evidence. Accumulation is form.

## FC-03 Process Geometry
Truth: 製作→取付まで一貫。

Bad: 3 Step Cards。

Good: 一つのVisual Objectが工程ごとに形を変え、完成状態へ到達する。

## FC-04 Material Resistance
Truth: 紙/木/塗膜など実物素材。

Bad: grain overlay。

Good: 重さ / 摩擦 / 重なり / 透過 / 塗膜の層がMotion/Easing/Maskへ反映。

## FC-05 Place Distance
Truth: 広い土地 / 複数施設 / 移動そのものが価値。

Bad: 写真Carousel。

Good: 距離 / 到着 / 遠景→近景をSection Transitionへする。

## FC-06 Product Behavior
Truth: 開く / 畳む / 回る / 切れる等の商品固有動作。

Bad: Feature Card。

Good: 商品の物理的動作がそのままContent RevealのRuleになる。

## FC-07 Founder Voice Rhythm
Truth: 代表者特有の話し方・短文・間。

Bad: Quote block 1個。

Good: Paragraph length / line break / section pauseそのものへ話し方を反映。

## FC-08 Local Taxonomy
Truth: 会社独自の分類語・商品名・工程名。

Bad: アイコン付きService Card。

Good: Navigation / Map / Section Naming自体を固有Taxonomyで組む。

# Prototype Hard Questions
各Prototypeは以下へYESが必要。

1. Truthを変えるとFormも変わるか？
2. 同業他社へ社名だけ替えて転用できないか？
3. Motionを止めても静止画として強いか？
4. 1 viewportで主張が一つか？
5. Mobileで同じ因果が残るか？
6. Fact Safetyを壊していないか？

3つ以上NOならPrototype破棄。
