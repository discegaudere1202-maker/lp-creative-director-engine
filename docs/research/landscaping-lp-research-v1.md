# 造園業 LP / 営業サンプル事前研究 v1

更新日: 2026-09-28
Owner: Sarah PM
Status: READY_FOR_TARGET_SELECTION

## 0. 目的

造園業の営業サンプルを、単なる「緑色の工務店LP」や「施工写真ギャラリー」にせず、対象事業者のCompany Truthから100万円クラスの完成度を狙えるよう、事業者選定前に業界固有のConversion / Trust / Visual / Scene Spec判断を準備する。

この研究はテンプレートを作るためではない。

- どのCompany Truthなら何を主役にするべきか
- 何が問い合わせ前の不安になるか
- 何をVisual Authorityにすべきか
- どのEvidenceが足りないと捏造リスクが出るか
- Scene Specに何を明示すべきか

を整理する。

# 1. 造園業を一括りにしない

営業サンプルでは、最初に対象を以下のArchetypeへ分類する。

## A. 庭木剪定 / 伐採 / 草刈り / 維持管理

主目的:
- 今ある困りごとを安心して頼める
- 料金 / 追加費用 / 対応範囲への不安を下げる

Primary Authority:
- TRUST
- BEFORE_AFTER
- CRAFT
- LOCALITY
- PRICE_CLARITY

強いEvidence:
- Before / After
- 料金目安
- 「見積後の追加費用なし」等の実在方針
- 1本から可 / 出張無料等の条件
- 対応地域
- 作業者 / 職人

参考:
- 一樹一会: 低木・中木・高木、生垣、草刈り等を具体的な料金目安で提示
- 中日本造園: 単価と「中間マージンなし」「地域密着」「強引な請求なし」を明示
- 庭史: LINE相談、無料相談、施工実績等を上部で早く提示

## B. 庭リフォーム / 新築外構 / エクステリア

主目的:
- 「この会社なら自分の暮らしに合う提案をしてくれそう」
- 金額が大きいので、デザイン / 施工力 / 予算 / プロセスを納得させる

Primary Authority:
- PLACE
- PHOTO
- DESIGN
- TRUST
- CONSULTABILITY

強いEvidence:
- 施工事例
- 建物との調和
- 予算帯 / 工事種別 / スタイル別の事例
- プランニング体制
- 資格 / 受賞 / 実績
- ヒアリング→提案→施工→管理の流れ

参考:
- 豊造園: 施工例を「種別 / コンセプト / 予算 / 部分」で探索可能にしている
- 庭史: プランナー、建築士、造園施工管理、デザイナー等の専門体制を訴求
- neutral: 年間施工件数と全国規模の受賞を強いProofとして利用

## C. 高級住宅 / デザイン造園 / 作品性重視

主目的:
- 「施工業者」ではなく「空間を任せたい設計・職人集団」として選ばれる

Primary Authority:
- PHOTO
- MATERIAL
- PLACE
- CRAFT
- EDITORIAL

強いEvidence:
- 建築との統合
- 石 / 植栽 / 水 / 光 / 経年変化
- 受賞施工
- デザイン思想
- デザイナー / 庭師の視点

参考:
- リム: 「外構ではなく空間」「レスデザイン」を軸にWorksとAward Worksを強く見せる
- Garden Elements: 建築と外構の調和を価値として提示
- neutral: モダン建築との調和、デザインで価値を上げる姿勢

## D. B2B / 公共 / 施設緑化まで含む総合造園

主目的:
- 対応範囲の広さだけではなく、相談のしやすさと一貫対応を理解させる

Primary Authority:
- SYSTEM
- TRUST
- CONSULTABILITY
- PLACE
- CASE_PROOF

参考:
- 竹中庭園緑化: 「困りごと」起点で曖昧な相談を具体サービスへ接続。Webグランプリ2025企業グランプリ部門コーポレートサイト賞優秀賞。

# 2. 業界固有のConversion Truth

## 2.1 施工写真だけでは足りない

施工事例は非常に強いが、問い合わせ判断には次の不安除去が必要。

- いくらくらいかかるか
- 自分の庭 / 家でも対応できるか
- どこまで頼めるか
- 追加費用が増えないか
- 自分の好みに合うか
- 植栽後 / 施工後も相談できるか
- 地域対応しているか
- どんな人が来るか

したがって、営業LPは `美しい施工写真 → 信頼証拠 → 依頼の具体化` までつなげる。

## 2.2 「相見積もり前提」の設計

外構は比較検討される前提が強い。価格だけではなく、以下の比較軸をLP側から先回りして示す。

- 設計力
- 植物知識 / 職人技
- 見積透明性
- 施工事例の近さ
- 施工後の管理
- 担当者 / 相談体制

## 2.3 高額工事ではBudget Navigationが効く

豊造園は施工事例を100万円台 / 200万円台 / 300〜400万円台 / 500万円以上に分類し、問い合わせフォームでも予算を聞いている。

高額案件の場合、金額を隠すより `予算別に何が可能か` を見せる方が相談の具体化に使える。

## 2.4 維持管理は「価格×安心×変化」の即時理解

剪定 / 伐採 / 草刈り系では、長いブランドストーリーより先に、

- Before / After
- 価格目安
- 追加費用ポリシー
- 対応範囲
- 連絡手段

が必要になりやすい。

# 4. 造園LPで避ける「テンプレ化」

以下を自動的に使わない。

- 緑 + ベージュ + 金の固定Palette
- 葉っぱアイコンを全sectionへ散らす
- Heroに「理想のお庭を叶えます」だけを置く
- 3カードで「技術力 / 対応力 / 安心」を並べるだけ
- ストックの庭写真を施工実績に見せる
- 造園業なのに植栽 / 土 / 石 / 経年の知識がVisualやCopyへ出ない
- 施工事例が単なるGalleryで、判断材料を持たない
- Awardロゴを大量に並べるだけ

Scene Specは対象事業者固有のEvidenceにより変える。

# 5. Visual Scene Specで持つべき造園固有パラメータ

## 5.1 Visual Authority

候補:
- `CRAFT`: 職人 / 剪定 / 石組 / 手仕事
- `PLACE`: 完成した庭 / 暮らしの場
- `MATERIAL`: 石・土・苔・樹皮・水
- `TRANSFORMATION`: Before / After
- `SEASON`: 四季 / 時間変化
- `ARCHITECTURE_RELATION`: 建築と庭の関係

Primary 1〜2、Secondary 1〜2に絞る。

## 5.2 Scene motifs

Company Truthが支持する場合のみ使う。

- 庭を横切る「園路」をscroll pathとして使う
- 植栽のlayeringをforeground / midground / backgroundのScene layeringへ置換
- 石組の非対称バランスをGridへ反映
- 木漏れ日をlight / shadow transitionとして使う
- 季節変化をsection progressionへ使う
- Before / Afterをwipe / split revealで表現
- 図面 / plan → completionのtransition
- 水の反射をsubtle motionへ使う

装飾のためだけに使わず、事業者の実態 / 写真 / Conceptと因果を持たせる。

## 5.3 Motion Grammar

推奨候補:
- gentle depth parallax
- foreground foliage reveal
- before / after drag or wipe
- plan-line draw
- light / shadow drift
- slow crop shift
- case-study staged reveal

禁止:
- 植物を大量にふわふわ浮かせる
- 理由のないGSAP spectacle
- 読了 / CTAを邪魔する過剰スクロールジャック

# 7. Truth-safe Sample Rule

営業サンプルでも実在会社について以下は捏造しない。

- 施工実績数
- 受賞歴
- 資格
- 創業年
- 料金
- 対応エリア
- 無料条件
- 顧客の声
- Before / After

実写真が不足する場合:

- generative / stock / mood imageを実績として表示しない
- `Design Direction / Image` と実績を区別する
- 実在する施工写真が公開されていればPublic Evidenceとして利用可否を確認し、営業サンプル利用ルールに従う
- 顧客の声は公開一次Sourceにあるもののみ

# 8. 事業者別に変えるべきページ構成

固定テンプレートにはしないが、判断開始点として以下を用意する。

## Maintenance-first
Hero → Immediate Proof / Price → Before After → Service → Why / Trust → Area → Flow → FAQ → CTA

## Design / Reform-first
Hero → Signature Works → Concept / Philosophy → Transformation / Cases → Design & Craft Proof → Service → Process / Budget → Voice → FAQ → CTA

## Premium Design-first
Hero → Manifesto / Place → Hero Case → Material / Craft → Works Sequence → Design Philosophy → Designer / Craftspeople → Process → Trust / Awards → CTA

## General Contractor / B2B Mixed
Hero → Needs / Problems → Solutions → Cases → Capabilities → System / Qualifications → Process → Area / Scale → CTA

# 9. 営業サンプルの品質Gate

対象事業者選定後、完成Sampleは最低限以下を見る。

1. 3秒で「何が得意な造園会社か」が伝わる
2. Company Truthを変えるとVisual Formも変わる
3. 施工写真 / Material / 職人 / Placeのうち主役が明確
4. 「他の造園会社でも使える見た目」になっていない
5. 問い合わせ前の不安を具体的に減らしている
6. CTAが会社の実在する相談方法に一致
7. Mobileで写真価値と問い合わせ導線を失わない
8. Motionに意味があり、造園の時間性 / 空間性とつながる
9. 架空のProofを使わない
10. 100万円クラスのHuman-visible Craft Detailを持つ

# 11. 次工程

Shunが対象事業者を選定したら、追加の一般業界研究は挟まず、以下へ直行する。

1. Target Evidence Audit
2. Archetype判定
3. Target固有のVisual Authority決定
4. Benchmark 3〜5件選択（模倣ではなく比較軸）
5. Copy / IA
6. Visual Scene Spec候補を複数生成
7. Validation visualでCreative ceilingを比較
8. 採用Scene SpecからHTML / Motion制作
9. 同一viewport QA / Human review

対象事業者の情報量が少ない場合でも、先にFact inventoryとUnknownを分離し、推測をCopy / Proofへ混ぜない。
