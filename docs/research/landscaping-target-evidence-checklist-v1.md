# 造園業 営業サンプル Target Evidence Checklist v1

更新日: 2026-09-28
Owner: Sarah PM
Status: READY

対象事業者が決まったら、この順でPublic Evidenceを回収し、UnknownとFactを分離する。

## A. Identity
- 正式社名 / 屋号
- 所在地
- 対応地域
- 電話 / Email / LINE / SNS
- 営業時間 / 定休日

## B. Service Matrix
- 剪定
- 伐採 / 抜根
- 草刈り / 防草
- 植栽
- 庭づくり / リフォーム
- 外構 / エクステリア
- 年間管理
- 法人 / マンション / 公共

## C. Proof
- 実施工写真
- Before / After
- 実績件数
- 創業 / 経験年数
- 資格
- 建設業許可
- 加盟団体
- 受賞歴
- 公共 / 法人案件

## D. Pricing / Conversion
- 価格 / 単価
- 見積無料
- 出張無料
- 相見積可否
- 追加費用ルール
- 最低注文条件
- 支払方法
- 問い合わせ方法

## E. Human / Craft
- 代表者
- 職人
- 仕事観
- 得意分野
- 得意樹種 / 工法 / デザイン
- 自社施工か協力会社か

## F. Visual Asset Inventory
各Assetを `PUBLIC_VERIFIED / USABLE_WITH_CAUTION / MISSING` で分類。

- Hero候補写真
- 横長施工写真
- 縦長施工写真
- 職人作業写真
- Material close-up
- Before / After pair
- 会社 / 車両 / 道具
- Logo

## G. Sample Safety Gate
以下はPublic Sourceにない限り作らない。

- 架空の施工実績
- 架空のCustomer Voice
- 架空のAward / Qualification
- 架空のPrice
- 架空の無料条件
- stock / generated imageをActual Worksとして表示

## H. Classification
Evidence取得後、対象を原則以下のいずれかに分類。

- MAINTENANCE_FIRST
- DESIGN_REFORM_FIRST
- PREMIUM_DESIGN_FIRST
- GENERAL_B2B_MIXED

複合の場合はPrimary / Secondaryを設定し、HeroとCTAの責任をPrimaryに寄せる。

## I. Build Gate
HTML制作へ入る前に最低限必要:

- Identity PASS
- Core Service PASS
- Contact route PASS
- Primary visual authority decided
- Truth-safe Hero copy
- Hero media strategy decided
- CTA claim verified

写真不足はBuildを止める理由ではないが、実績誤認を生む使い方は禁止する。
