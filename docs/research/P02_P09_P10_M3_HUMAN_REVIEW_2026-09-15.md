## Purpose

This review exists to prevent a capture-success shortcut from becoming an M3 shortcut. A benchmark is useful for a formal tournament only when the live external 390×844 and 1440×1000 frames are visually reviewed and the captured frame actually tests the same problem as the prototype.

The standard remains:

> Capture is evidence acquisition. Human visual review decides whether the evidence is tournament-grade.

## P09 — Price Transparency

The benchmark problem is not simply “does the page contain a price?”. The frame must make price, price drivers or plan differences, and the path to action understandable at a glance.

### PASS / M3

#### Aki Design

Decision: **PASS / M3**

Why it belongs:

- public prices are treated as a designed information object rather than buried in body copy;
- three price levels remain readable in the mobile state;
- the restrained composition gives P09 a strong craft opponent rather than a utility-only table.

#### Studio Pricing

Decision: **PASS / M3**

Run 8 evidence:

- exact 390×844 and 1440×1000 captures;
- HTTP 200;
- no horizontal overflow (`scrollWidth == clientWidth`);
- mobile screenshot SHA-256: `4c4a82ac4a995242f326b797e9da9aac59592ae11ff902d75d593476c5058cff`;
- desktop screenshot SHA-256: `8caaccb723885a11ba1a3b2e67d5c6c2d1f67678d261b350145dd33e3c1a901c`.

Why it belongs:

- monthly/annual price, intended customer type and plan features coexist in the same mobile frame;
- the 390px layout is deliberately vertical and does not depend on horizontal comparison-table overflow;
- price transparency and conversion action are both present.

### HOLD / REJECT

#### kintone Price — Run 8 frame

Decision: **HOLD pending recapture**

The page itself has strong pricing information, but the Run 8 target focused on “3つのコース”. The first 844px showed the pricing-page introduction and course heading, not the actual public price rows. A beautiful page is not enough if the captured tournament frame tests the wrong thing.

Run 9 changes the focus to `月額1,800円` so that the actual price / plan comparison frame can be reviewed.

#### LSHORT

Decision: **HOLD / reserve**

- exact mobile capture and clear public price;
- price and feature differences are understandable;
- however, visual/craft strength is more conventional than Aki Design / Studio, so it is not used merely to reach three opponents while a stronger kintone frame is available to pursue.

#### OurPhoto

#### A LOT OF / CNDoor
