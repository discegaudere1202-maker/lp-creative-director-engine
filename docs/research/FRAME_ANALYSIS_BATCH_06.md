## 78. 東洋紡 コーポレートサイト — FRIENDLY B2B INFORMATION ARCHITECTURE

### Source-derived
2023 Webグランプリ企業BtoBサイト賞優秀賞。

Sources:
https://award.dmi.jaa.or.jp/winner/gp11c_report
https://award.dmi.jaa.or.jp/winner/gp11c_detail/525

### Internal interpretation

### Transfer rule
事業/サービス数が多い案件では `information classification → navigation clarity → visual warmth` を先に設計する。

Visual Authority: INFORMATION / UTILITY
