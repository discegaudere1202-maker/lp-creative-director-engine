# Core Frame Selection Rules v1

Updated: 2026-09-15

## Goal
Source-backed Explicit Ledger 100件を、営業Sampleの品質上限を直接引き上げる**60 Core Benchmark Units**へ削る。

Core = 有名/受賞/派手、ではない。
`NO_WEB / WEAK_WEB`の個人事業主・中小企業へArt Direction判断を移植できることを最優先する。

---

# 1. Selection dimensions

各候補を0–5で内部評価する。

## A. Sales-transferability
NO_WEB / WEAK_WEBの営業Sampleへ判断を転用しやすいか。

5:
- 公開Factだけでも応用可能
- 写真が少なくても学びが使える
- Local SME / BtoB / Service / Shop等へ広く使える

1:
- 巨大Brand固有予算/権利/Assetがないと成立しない

## B. Form Causality
Company/Brand/Product TruthがFormの原因になっているか。

5:
- Truthを変えるとLayout/Motion/Type ruleも変わる

1:
- 流行の見た目へ情報を載せただけ

## C. Screenshot-worthiness
一画面だけでもHierarchy / Tension / Afterimageがあるか。

## D. Conversion / Trust relevance
問い合わせ・来店・応募・購入・理解・信頼に接続する学びがあるか。

## E. Craft depth
Typography / Crop / Light / Motion / Spacing / Editing等、専門Passへ分解できるか。

## F. Mobile / Accessibility relevance
Desktop-only spectacleでなく、Mobile/Accessibility/Utilityへ学びがあるか。

## G. Non-duplication
他のCore候補では代替できない学びか。

---

# 2. Core inclusion rule

原則:
- A Sales-transferability >= 3
- B Form Causality >= 3
- 7 dimension合計 >= 25/35

例外採用:
- Sales-transferabilityが2でも、特定Authorityの最高Benchmarkとして必要
- Accessibility / Mobile / Photo DirectionなどCoverageを守るため必要

---

# 3. Exclusion reason codes

`DUPLICATE_LESSON`
同じSite/同じ学びの強いCoreが既にある。

`AWARD_ONLY_SPECTACLE`
技術/演出は強いが、営業LPへ移植できる判断が薄い。

`ASSET_DEPENDENT`
大型撮影/権利IP/予算が成立条件で、一般営業Sampleへの転用が弱い。

`LOW_FORM_CAUSALITY`
見た目は良いがTruth→Form因果が弱い。

`LOW_CONVERSION_RELEVANCE`
Screenshot研究には面白いが、事業成果/信頼/理解への学びが薄い。

`LOW_DIFFERENTIATION`
他のBenchmarkより学びが一般的。

`KEEP_AS_SECONDARY_REFERENCE`
Core60には入れないがAuthority別補助Referenceとして保持。

---

# 4. Coverage floor

Core60全体として最低限持つ。

- PERSON / EDITORIAL: 6+
- MATERIAL / PHOTO / CRAFT: 6+
- PRODUCT BEHAVIOR: 4+
- PLACE / HOSPITALITY: 4+
- DOCUMENT / B2B / EXPLAINER: 7+
- WORLD / SYSTEM / CATEGORY: 7+
- TYPOGRAPHY / MOTION: 5+
- UTILITY / ACCESSIBILITY / TRUST: 7+
- CONVERSION / CTA / ACTION: 7+

Tagは重複可。

---

# 5. SME relevance check

各Core候補へ最後に問う。

**この学びを、Webを持っていない地域の看板屋・士業・飲食店・工務店・製造業・美容店などへ、事実を捏造せず応用できるか？**

YESの説明ができない場合、Coreから外す。

ただしMaterial/Place/Product等のAuthority最高基準として必要ならSpecialist Benchmarkとして残せる。

---

# 6. What Core60 is not

- Layout template集ではない
- 色/Fontコピー集ではない
- Award site imitatorではない
- 60種類のLP templateではない

Core60は、
**“どういうCompany Truthなら、どんなArt Direction判断が高品質になり得るか”を比較する判断辞書。**
