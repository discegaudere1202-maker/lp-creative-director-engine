# Benchmark Pool v1

更新日: 2026-09-15

目的: Blind Tournamentで使う日本サイトの比較母集団を、単なる受賞歴ではなく「何の比較に使えるか」まで整理する。

> 注意
> - ここに入っただけでCOREではない。
> - Benchmarkは営業LPへ見た目をコピーするためのものではない。
> - Company Truth / Visual Authority / Conversion目的が近いものだけ比較相手に使う。
> - Award受賞 = CVが高い、ではない。Craft BenchmarkとConversion Benchmarkを分ける。

# Pool運用ルール

## 1. Benchmark selection
CandidateのPrimary Visual Authorityと目的に応じ、3〜5件を選ぶ。

例:
- Asset-poor士業 → B04 + Trust/Editorial系
- 職人/工芸 → B02 + B08 + Material系
- Person brand → B01 + Editorial Persona系
- 採用 → B03 + B06 + B07

## 2. 禁止
- Award順位だけで比較相手を決める
- 見た目が似ているから選ぶ
- Benchmarkの色・Grid・Motionをコピーする

## 3. CORE昇格
CORE Benchmarkへ昇格するには:
- Source rationale確認
- Desktop visual確認
- Mobile visual確認
- 何を比較するBenchmarkか明確
- 模倣ではなく原理として言語化済み

## 4. 今後
このPoolを最低20〜30件へ増やし、Visual Authorityごとに3件以上のCOREを持つ。
