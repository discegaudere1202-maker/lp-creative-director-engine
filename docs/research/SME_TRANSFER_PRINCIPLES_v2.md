# SME Transfer Principles v2

Updated: 2026-09-15

This document extracts principles from high-quality Japanese sites that can transfer to NO_WEB / WEAK_WEB individual businesses and SMEs without copying award-site styling.

## 1. Work style can become the visual scene
Reference: MeUMU.
If the company has a distinctive way of working, show one concrete situation that embodies it instead of writing an abstract value statement.

Sales-sample transfer:
- client + owner + staff around one problem
- field worker checking one real object
- craftsperson completing the final step

Avoid: generic process cards.

## 2. Specialist language should be translated into the customer's world
Reference: 日進化成.
Do not open with inventory of technical terms. Explain what the specialist work changes in the customer's daily reality.

Sales-sample transfer:
- legal term → actual situation
- material name → outcome in the shop/factory/home
- repair category → symptom the customer notices

## 3. Emotional barriers deserve their own art direction
Reference: 実家のこと。
For heavy topics, the first creative problem can be psychological permission rather than feature explanation.

Sales-sample transfer:
- 相談するほどか分からない
- 怒られそう
- 価格が怖い
- 何を聞けばいいか分からない

The visual temperature must reduce this barrier without becoming childish.

## 4. Product/service concepts can drive real form
Reference: KAGAMI.
A concept like reflection can become material, illustration and section language while the site still carries long-form proof.

Sales-sample transfer:
Use a visual metaphor only if it is directly rooted in the company's actual behavior, wording, product or customer transformation.

## 5. Category novelty still needs understanding and action
Reference: StartPass.
A new or unfamiliar service can use strong typography and visual impact, but must invest equally in staged explanation and action design.

Sales-sample transfer:
A striking Hero is not allowed to postpone "what is this / why me / what next" for too long.

## 6. Brand verb can become a motion/composition grammar
Reference: IMA.
A verb such as "かきまぜる" can generate shape and motion. This is stronger than decorating a headline with animation.

Sales-sample transfer:
Extract verbs from real work:
- cut
- align
- layer
- carry
- untangle
- polish
- translate
- fit
- protect
- compare

## 7. Photos are not mandatory, but real assets dominate when strong
For NO_WEB sales samples with no photos, create a complete art-directed state without fake reality. After contract, client evidence slots enrich the frame.

Rule:
Client Evidence must enrich, never rescue.

## 8. Mobile is an art-direction state
Do not approve a frame as Benchmark CORE from desktop evidence only.

Mobile can change:
- order
- crop
- alignment
- visual-first/copy-first sequence
- type scale
- interaction density

But must preserve Company Truth → Form.
