### Source-derived

`learn / understand / decide` の順に情報を編集し、広告臭を下げる選択肢を持つ。

# Batch 05 synthesis

追加20件から、営業Sampleへ特に重要な原則を5つ抽出する。

1. **Premium ≠ Visual excess**
   岩崎電気・Lumiarch・中外製薬のように、抑制・読みやすさ・Utility自体が品質になる。

2. **Product/Placeは体験を先に証明できる**
   Shupatto・ビートルランド・新千歳空港では、説明より先に使い方/過ごし方/体験価値を感じさせている。

3. **難しいBtoBは“入口の翻訳”が重要**
   明電舎・Voice by TOYOBOは、専門性を落とさず親しみやすい入口を作っている。

4. **Brand WorldとConversionは両立する**
   グリーンパーク山東・おくすりシートリサイクルは、魅力と実際の行動を同時に設計している。

5. **AccessibilityはPremium Craftの一部**
   中外製薬・日ハム式未来マップから、AccessibilityをRelease後の追加対応にしない。
