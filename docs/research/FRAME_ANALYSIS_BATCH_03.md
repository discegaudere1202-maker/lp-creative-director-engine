# Batch 03から追加した重要ルール

## Rule A — Peakの種類を増やす
Screenshot-worthyは「巨大タイポ」だけではない。

- Personality Peak
- Material Peak
- Editorial Peak
- Trust Peak
- Interaction Peak
- Radical Edit Peak
- World Peak
- Utility Peak

## Rule B — Award表現を営業LPへそのままコピーしない
Award Siteは研究材料。
営業Sampleでは、
- Target
- Pain
- Proof
- CTA
- Owner Truth
が必要。

## Rule C — Company Truth → Form
Batch 03の強い例ほど、
「なぜこの形か」が会社・テーマの事実から説明できる。

## Rule D — SimplicityもPeakになりうる
SmartHR / 帝国ホテル / ニッカ等から、
Premiumを“演出量”で測らない。
