## 1. What actually happened

Issue #119 correctly identified a missing research-pattern → Production Variant → renderer → screenshot bridge. Issue #121/#124 then implemented traceable variants and whole-page continuation families. That repaired **structural divergence**.

It did not repair **premium perception**.

The actual Issue #124 owner bundle shows:

- 9 pages.
- Every page contains exactly **2 `<img>` elements**: 18 total.
- Each page contains **5–7 `<section>` elements**, so media placements are sparse relative to page length.
- All images are rendered through the same outer `production-asset` primitive.
- All pages use the same two font-family variables (`--sans`, `--serif`) and six animation declarations.
- Only three stylesheet hashes occur across the nine delivered pages.
- Whole-page Spine traces start with `hero_dominant_context` + `local_media_if_bound`; most later beats are `copy_evidence_only`.

So an image can exist, load correctly and still be perceived as “not there”: it has too little page-level continuity, authority and narrative responsibility.

## 2. Before/after reality

The Issue #124 1440/390 contact sheets are longer and contain more authored continuation geometry than the Issue #121 contact sheets. Compare/route/evidence continuations are materially different in structure.

However, the public visual lineage remains close:

- restrained white/neutral fields;
- recurring line/ledger/card/rail material;
- shared type vocabulary;

That is why “clone signatures diverged” and “前のとほとんど変わってない” can both be true.

## 4. Root cause

### RC-01 — Structural fidelity ≠ perceptual fidelity
Pattern IDs, renderer identities and different DOM silhouettes prove implementation diversity, not premium visual effect.

### RC-02 — Media is still an asset binding, not an art-direction system
Two images carry an entire 5–7-section page. The continuation arc is mostly copy/evidence-only, so imagery cannot sustain world-building, process, transition, atmosphere or editorial rhythm.

### RC-03 — Page Spine is not pixel-authoritative enough
The Spine coordinates semantic continuation, but typography, material grammar, media rhythm and focal sequencing remain too shared/restrained.

### RC-04 — Benchmark qualities were compressed into names
“route”, “evidence”, “compare” and “process” survive as mechanisms, while the benchmark's visual force—image dominance, editorial sequencing, material crops, density contrast, type authority—is not guaranteed.

### RC-05 — Aoi's review order was wrong
Issue #126 asked whether the clone/skeleton failure was fixed. Aoi correctly found more divergence, but divergence became too strong a proxy for overall quality.

Two pages can be different from each other and both still be weak.

### RC-06 — No hard rejected-baseline delta gate
The system proved new signatures; it did not force a blind first-glance escape from the latest Shun-rejected visual lineage.

### RC-07 — Owner evidence chain is not closed
The packaged baseline/current owner HTML duplication means before/after delivery evidence itself can be ambiguous.

### Media Narrative Plan
Do **not** invent a universal minimum image count.

Instead, every media binding declares:

- narrative role;
- compositional role;
- prominence intent (`dominant`, `co-dominant`, `supporting`, `none_by_design`);
- evidence status;
- crop / geometry / layering;
- copy interaction;
- transition role;
- desktop behavior;
- mobile re-art-direction;
- fallback restriction.

Image-led mechanisms must visibly stay image-led. If truth/rights/media feasibility cannot support a selected mechanism, fail closed or adapt to a compatible variant **inside the already frozen Family**. Never silently reduce it to a small generic image slot.

### Section authorship
Every major scene needs a visible reason for its composition: focal hierarchy, type/media relation, negative space, adjacency/transition and material behavior. A different class, border, dark panel or grid ratio is not enough.

### Typography / material / spacing
Shared font variables can be infrastructure, but the resulting type relationship must create page-specific authority. Material grammar cannot collapse to one universal ledger/card/rail premium skin. Spacing must have an intentional arc, not merely generous padding.

### Screenshot-worthy authored moments
Each page must contain clear focal moments that are recognizable without metadata. No global arbitrary count is prescribed; the benchmark mechanism and persuasion arc determine the required breadth.

### Desktop + mobile
1440 and 390 are separate art-direction surfaces. Mobile may simplify, but cannot erase media authority, type hierarchy, state transitions or closing resolution.

### Rejected Baseline Delta Gate
Before checking sibling uniqueness, compare current 1440/390 directly against the latest Shun-rejected version. RETURN when the current page remains materially tied to the rejected version in:

- macro silhouette;
- typography relationship;
- media rhythm;
- density cadence;
- material grammar;
- focal scene sequence;
- ending behavior.

Do not invent a numeric similarity threshold.
