# 3. Blocker 1 — S3/S4 desktop authored composition correction

## 3.1 Shared authored principle

S3 and S4 must feel like **media and copy are intentionally in dialogue**, not like one layer happened to land on top of the other.

The integration mechanism is **adjacency + controlled field tension**, not text-on-photo collision.

### Non-negotiable desktop rule

At every desktop/tablet breakpoint, the rendered headline/body bounding box must not intersect the visible high-contrast area of the representative image.

A minimum optical safety gap must remain between the copy safe zone and the media authority zone:

- 1440: `>= 64px`
- 1280: `>= 56px`
- 1024: `>= 40px`
- 768: `>= 32px`

If Rin cannot preserve both the gap and legible copy at a breakpoint, the correct fallback is **reduce media width / remove tilt / reduce overlap**, never shrink copy below the semantic hierarchy floor.

---

## 3.2 S3 — RECEIVE / ドライヘッドスパ

### Customer job

Move from “I may simply want a pause” to “this service is the relevant entry point for that state.”

### 1440 authored frame

Use the 1440 content canvas as two unequal but non-colliding authority zones.

**Copy safe zone**

- left edge: `max(96px, 7vw)`
- right edge: `<= 650px`
- top: `150–190px`
- bottom: `<= 800px`
- headline max width: `520px`
- body max width: `500px`

**Media authority zone**

- left edge: `>= 735px`
- right bleed allowed to `1440px + 24px`
- top: `120–150px`
- bottom: `<= scene height - 70px`
- target width: `620–690px`
- target height: `72–78%` of scene visual height

**Tilt / crop**

- rotation: `-1.5deg to -2.5deg`; never beyond `-3deg`
- no diagonal edge may cross the copy safe zone
- preserve a stable head/hand/service-detail focal area; do not crop the meaningful service gesture out of frame
- the darkest/highest-contrast region must remain on the media side of the 64px safety gap
- clip-path may remain asymmetric, but only one dominant diagonal direction; do not add a second ornamental diagonal

**Hierarchy**

1. eyebrow `受ける`
2. service headline `ドライヘッドスパ`
3. customer-state body
4. representative image as emotional/experiential support
5. disclosure remains visible but subordinate

The image must not become pseudo-evidence of Nagi staff/premises.

### Background transition

S2 → S3 should move from choice/orientation into a quieter experiential field.

- Keep S3 materially cooler/softer than S2.
- Do not add extra gradients or decorative planes behind the copy.
- One background field + one media field is sufficient.
- Background contrast behind all text must remain visually stable; no image edge behind headline/body.

### Why this is more persuasive

The customer can first recognize their own state, then see a representative sensory cue without sacrificing reading order. The media supports imagination **after** the service relevance is legible.

## 3.3 S4 — LEARN / ヘッドスパスクール

### Customer job

Move from “the technique itself is becoming interesting” to “there is a learning entry point worth asking about, even though the detailed curriculum is still unknown.”

### 1440 authored frame

Reverse the authority balance from S3 so the page does not repeat one split template.

**Media authority zone**

- left edge bleed allowed to `-24px`
- right edge: `<= 645px`
- top: `135–165px`
- bottom: `<= scene height - 80px`
- target width: `610–670px`
- target height: `68–76%`

**Copy safe zone**

- left edge: `>= 735px`
- right edge: `<= 1340px`
- top: `155–190px`
- body width: `500–540px`
- headline width: `540px`

**Tilt / crop**

- rotation: `+1deg to +2deg`; never beyond `+2.5deg`
- the crop must preserve the learning/detail cue that makes the image read as “technique/learning interest” rather than generic relaxation
- no media shadow, clip edge, or high-contrast region may enter the 64px copy gap
- shadow may exist only outward from media, never into copy

**Hierarchy**

1. eyebrow `学ぶ`
2. headline with customer tension
3. short persuasion paragraph
4. explicit UNKNOWN / ask-before-deciding line
5. representative media

UNKNOWN information must be visually quieter than the main persuasion, but not hidden.

### Background transition

S3 → S4 must feel like a **mode change from receiving to learning**.

- S4 may retain the warm/ivory field.
- Do not place text across an image/background seam.
- If an image crop creates strong tonal variance near the copy side, add a neutral 40–64px buffer field rather than an overlay on the text.

## 3.4 Desktop degradation rules

### 1280

- Preserve two-zone composition.
- S3 copy width `<= 520px`, media width `<= 560px`.
- S4 media width `<= 550px`, copy width `<= 500px`.
- Safety gap `>= 56px`.
- Tilt maximum absolute value `2deg`.

### 1024

- Keep side-by-side only while headline and body remain at intended hierarchy.
- Grid target: `46/54` or `45/55`, not 50/50 by default.
- Safety gap `>= 40px`.
- Remove decorative box-shadow if it visually closes the gap.
- Tilt maximum absolute value `1.25deg`.
- No text may sit on transparent image edge.

### 768

Treat as a bridge to mobile, not shrunken desktop.

- No overlap.
- Two-column is optional; if used, image and copy must remain fully separate.
- Preferred fallback: headline + short opening line in first block, media in second block, remaining copy in third block.
- Media width `100%` of inner content or controlled edge bleed `<= 24px`.
- Tilt `0–0.75deg`; default `0deg` if crop confidence is low.
- Minimum vertical separation between copy and media `28px`.

# 4. Blocker 2 — Final customer-facing copy

- The copy must speak to a customer, never to the production process.

   - `ドライヘッドスパを探すのは、そんな日かもしれません。`

# 10. Acceptance criteria — designed to catch the exact Round 3Q regressions

## AC-01 S3/S4 1440 collision hard check

PASS only if:

- headline/body bounding boxes do not intersect image or image-shadow bounding boxes;
- optical safety gap is `>= 64px`;
- no high-contrast image region visually runs behind the copy field;
- disclosure does not overlap headline/body;
- image remains compositionally meaningful and not reduced to a generic card.

Any collision = `RETURN` regardless of Browser QA green state.

## AC-02 Desktop degradation

At 1280 / 1024 / 768:

- no overlap;
- copy hierarchy stays materially equivalent;
- no emergency tiny type;
- crop does not lose the scene's representative role;
- no horizontal overflow.

## AC-03 Copy exactness

Rendered S1/S2/S4/S5/S7 copy must match the approved customer-facing text, allowing only punctuation-normalization that does not change meaning.

Forbidden customer-visible language includes:

- `文面の例です`
- `実際には〜置き換えてください`
- internal IA/state-map terminology
- AI/process explanations
- invented benefit/effect/proof

## AC-04 Customer-state movement

Human reviewer must be able to state, scene by scene:

- S1: three real Nagi entry modes are understood.
- S2: customer self-identifies without forced commitment.
- S4: learning curiosity gains a safe next question.
- S5: category uncertainty is reduced without fabricated explanation.
- S7: contact friction drops without tutorial tone.

If a scene merely explains its category, it fails even if the copy is safe.

## AC-05 Mobile authorship 390

S3/S4 must not both render as identical `headline → all body → image` stacks.

Required:

- S3: opening sentence → media → remaining body.
- S4: headline → media → persuasion body → UNKNOWN line.
- no overlap;
- deliberate crop; no blind center-crop;
- spacing creates clear scene rhythm.

## AC-06 Small-width degradation

320 / 360 / 375 / 430:

- no overflow;
- no truncated content;
- no one-word or particle orphan introduced by forced breaks;
- media never pushes CTA/content off usable flow;
- no desktop absolute positioning survives if it harms reading order.

## AC-07 Preserve S6

Round 3S candidate must retain S6 as a clear trust/information-authority break. If S6 is weakened while fixing S3/S4, overall result is a regression.

## AC-08 Evidence/media safety

- all representative media remains disclosed as representative/imagery where required;
- no new Nagi-specific staff/premises/customer implication;
- no unknown factual field becomes assertive copy.

## AC-09 Verified contact

Every external conversion target introduced or preserved by this change points only to the verified official Instagram route.

## AC-10 Human-visible gate
