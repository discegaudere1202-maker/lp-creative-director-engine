# LP Creative Director Engine v0.4 — Release Notes

更新日: 2026-09-15

## Added
- DOM section boundary capture during Tier-2 Visual QA
- Section-level pixel metrics
- Section-to-section transition energy
- quietest / densest section observation
- strongest visual gear-change observation
- section pixel metric unit test

## Why
Full-page 24-band rhythm is useful, but cannot answer *which section* creates a flat or over-quiet interval.
v0.4 binds rendered pixels back to actual DOM section IDs.

## Rule
These metrics remain **OBSERVATION ONLY**.
They do not override Creative Red Team, Screenshot Score, CRO or Owner Specificity.
